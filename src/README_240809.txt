스마트 라이더 앱 개발 리드미
프로젝트 개요
스마트 라이더 앱은 건물 정보를 등록, 조회, 관리할 수 있는 React 기반의 웹 애플리케이션입니다. Firebase를 백엔드로 사용하며, 로컬 데이터 저장을 위해 IndexedDB를 활용합니다.
주요 기능

건물 등록
건물 조회 (검색 기능 포함)
건물 상세 정보 확인 및 수정
공지사항 및 제안하기 기능
사용자 인증 (로그인/로그아웃)

기술 스택

Frontend: React, React Router
Backend: Firebase (Realtime Database, Authentication, Storage)
로컬 저장소: IndexedDB, Local Storage
스타일링: Tailwind CSS

주요 컴포넌트

App.js: 메인 애플리케이션 컴포넌트
Home.js: 홈 화면
Register.js: 건물 등록 화면
Search.js: 건물 검색 화면
Detail.js: 건물 상세 정보 화면
SideMenu.js: 사이드 메뉴 컴포넌트

데이터 구조

Firebase Realtime Database:

buildings: 건물 기본 정보 (이름, 특이사항, 샛길 정보, 이미지 URL 등)
notices: 공지사항
popup: 팝업 정보


IndexedDB:

buildings: Firebase의 buildings 데이터 미러링


Local Storage:

buildingMemos: 각 건물의 입출입 특이사항 메모 (사용자별 개인 데이터)

1. 데이터 마이그레이션 및 동기화

해결: App.js에서 마이그레이션 로직을 수정하여 IndexedDB에 데이터가 없을 때만 Firebase에서 데이터를 가져오도록 변경

    try {
      const buildingsList = await getAllBuildings();
      if (buildingsList.length === 0) {
        // Firebase에서 데이터 가져오기 및 IndexedDB에 저장
        // ...
      } else {
        setBuildings(buildingsList.reverse());
      }
    } catch (error) {
      console.error('Error loading data:', error);

  loadData();

해결: Home.js 컴포넌트에서 buildings prop을 사용하여 최근 5개 건물을 표시하도록 수정

}

4. 뒤로 가기 버튼 동작 개선
문제: 홈 화면에서 뒤로 가기 버튼 클릭 시 이전 화면으로 이동
해결: App.js에서 커스텀 뒤로 가기 핸들러 추가
javascriptCopyuseEffect(() => {
  let backPressCount = 0;
  let backPressTimer;

  const handleBackButton = (e) => {
    if (location.pathname === '/') {
      e.preventDefault();
      backPressCount++;
      if (backPressCount === 2) {
        alert('앱을 종료합니다.');
      } else {
        backPressTimer = setTimeout(() => {
          backPressCount = 0;
        }, 2000);
      }
    } else {
      navigate(-1);
    }
  };

  window.addEventListener('popstate', handleBackButton);

  return () => {
    window.removeEventListener('popstate', handleBackButton);
    clearTimeout(backPressTimer);
  };
}, [location, navigate]);
